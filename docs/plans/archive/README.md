Gordian Envelope migration. Kept as historical reference; **not**
authoritative for current behavior. For current architecture and
wire format, see:

- [`docs/architecture.md`](../../architecture.md)
- [`docs/wire-protocol.md`](../../wire-protocol.md)

the protobuf → Gordian Envelope migration; references to
`recrypt-proto`, `prost`, and protobuf types reflect the state at
the time of writing.
